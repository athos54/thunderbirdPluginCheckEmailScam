INSTALACIÓN RÁPIDA:
-------------------
1. Abre Thunderbird
2. Ve a: Menú ☰ → Complementos y temas
3. Click en el engranaje ⚙️ → "Instalar complemento desde archivo"
4. Selecciona: email-spam-checker.xpi
5. Confirma la instalación


CONFIGURACIÓN (OBLIGATORIA):
----------------------------
Necesitas una API key de OpenAI:

1. Ve a: https://platform.openai.com/api-keys
2. Crea una cuenta (si no tienes)
3. Genera una nueva API key
4. IMPORTANTE: Añade crédito ($5 mínimo) en:
   https://platform.openai.com/settings/organization/billing

5. En Thunderbird:
   - Abre un email
   - Click en el icono del plugin (escudo azul)
   - Click en "Configuración"
   - Pega tu API key
   - Guarda


USO:
----
1. Abre cualquier email en Thunderbird
2. Click en el icono del plugin 🛡️
3. Click en "Analizar este email"
4. Se abre una ventana con el análisis completo


QUÉ ANALIZA:
------------
✓ Cabeceras SPF/DKIM/DMARC
✓ Enlaces (acortadores, typosquatting, punycode)
✓ Homoglyphs (O/0, l/I, caracteres Unicode)
✓ Ingeniería social (urgencia, amenazas)
✓ Evaluación del dominio basada en las evidencias del email
